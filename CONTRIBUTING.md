# Contributing

Thanks for helping the universe grow. For a first contribution, a small original preset, accessibility improvement, test, or performance fix is ideal.

1. Open an issue describing the behavior or visual concept.
2. Create a focused branch and run `npm test` plus `npm run build`.
3. Include a screenshot or short recording for visual changes.
4. Confirm that contributed audio, textures, shaders, and fonts can be redistributed under their stated licenses.

Preset updates must avoid per-frame allocation, implement `dispose`, work with reduced motion, and remain usable with mouse, touch, and keyboard controls.
